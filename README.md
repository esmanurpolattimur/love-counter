# Aşk Sayacı

Çiftlerin birlikte geçirdiği zamanı gösteren Flutter mobil uygulaması.

## MVP kapsamı

- İki isim ve ilişki başlangıç tarihi girişi
- Büyük gün sayacı ile yıl, ay, gün ve saat özeti
- Bilgilerin cihazda `SharedPreferences` ile saklanması
- Kayıtlı bilgileri düzenleme

## Çalıştırma

Bu bilgisayarda Flutter SDK'sı henüz bulunmuyor. Flutter kurulduktan sonra proje kökünde aşağıdaki komutlar çalıştırılmalıdır:

```powershell
flutter create .
flutter pub get
flutter run
```
